为什么是 eduby

不止是题库,是学习方式。

我们用更聪明的方式,让知识真正进入你的大脑。

✦

知识图谱

把零散的知识点连成网络,看清每一步的前因后果,不再孤立地死记硬背。

⚡

智能间隔重复

基于记忆曲线的复习算法,在遗忘临界点提醒你,记得更牢,花的时间更少。

◎

学习社区

和同年级、同爱好的同学一起讨论、答疑、分享笔记。学习不是孤军奋战。

✺

开源开放

所有内容、所有代码,任何人都可以查看、贡献、改进。教育本该是公共的。

Open Source

为开源工作者设计。

eduby 本身就是一个开源项目。 如果你是开发者,我们为你准备好了清晰的代码、友好的流程、和一个真正被尊重的协作环境。

  • ✓
    清晰的代码规范 就像写作文有格式,代码也有规范。我们的规则简单、文档齐全,新人一小时就能上手,不必在"屎山"里考古。
  • ✓
    透明的决策过程 所有功能、界面调整,都在 eduby 公开讨论。你的意见,不会被丢进黑洞。
  • ✓
    有意义的贡献 每一份代码、每一篇内容,都会被认真审阅;每一位贡献者都会被看见。贡献墙永远亮着。
  • ✓
    教育本身是公共的 我们不接受影响内容中立的合作。学习者该信什么,不该由广告主决定。

# eduby 的知识图谱:让每个点,连成一张网
# 你已经掌握了一些知识点,系统就会推荐它的"邻居"

def study_now(mastered, graph):
scored = []
for topic, neighbors in graph.items():
if topic in mastered:
continue
# 邻居越多 → 现在学越划算(举一反三)
ready = neighbors & set(mastered)
scored.append((len(ready), topic))
scored.sort(reverse=True)
return scored[0][1]

# 你已经会了「牛顿第二定律」
# 系统就会推荐「动量守恒」—— 因为它就在隔壁 ✨
